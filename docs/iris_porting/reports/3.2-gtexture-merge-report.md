## What changed

- **`shader/.../pipeline/transform/transformer/CommonTransformer.java`**
  - New `renameGtexture(ShaderAst)`. It runs a nested `Upstream` holder inside `ast.build` (PORTING_GUIDE rules 1-3).
  - The holder copies these from Iris (I `CommonTransformer.java:319-349,389-436`):
    - the `sampler` matcher (`uniform Type name;` with a SAMPLER builtin type);
    - the merge block from `transform`;
    - `getGtextureRenameTargets`;
    - `RenameTargetResult`.
  - Rename rules:
    - A name counts only if a file-scope declaration of it is a `uniform` sampler.
    - A non-sampler file-scope declaration of the name turns the rename off.
    - Every use of the name that is not a call becomes `gtexture`.
  - When both names are declared:
    - `gcolor`'s declaration member is kept and renamed `gtexture`.
    - `texture`'s declaration is deleted. If it shares a declaration with `gcolor` (`uniform sampler2D gcolor, texture;`), only its member is removed.
  - The three TauMC verb renames in `CommonTransformer.transform` are removed. They were at old `:119-129`; the brief says `:101-111`.
- **`shader/.../pipeline/transform/ShaderTransformer.java`**
  - `doTransform` calls `CommonTransformer.renameGtexture(ast)` after the patch switch and before `TextureTransformer.transform`.
  - Reasons for that position:
    - Idiom code runs after the stage's verbs (PORTING_GUIDE rule 3).
    - `TextureTransformer` renames samplers by name, and Iris also runs the merge before its TextureTransformer.
  - All six patch kinds called `CommonTransformer.transform`, so the merge still reaches the same stages.
- **Departures from upstream.** Each one has a `// Demonica:` comment.
  1. The texture name is `actinium_renamed_texture`. That is the name the `GlslTransformUtils.replaceTexture` pre-pass gives every `texture` not followed by `(`, and `restoreReservedWords` gives the name back at print.
  2. The TauMC fallback `if (ast.hasVariable(actinium_renamed_texture)) ast.rename(..., "gtexture")` is kept after the merge.
     - It catches a `texture` the merge does not take, such as a local variable or a non-sampler declaration.
     - Without it, the restored name would hide the `texture()` builtin.
     - Iris leaves such a name alone.
     - When the merge did take the name, this branch does nothing.
  3. Identifiers are visited in the document order of their top-level external declaration. Iris uses the `identifierIndex` HashSet order, in which "the first declaration met decides" is not deterministic (rule 2).
