# I1: a synchronous terrain search under a shadow pass

Draft, not sent. Replaces `getAsyncOcclusionMode` in
`seam.VintageRenderSectionManagerShadowMixin` (group SHADOW).

## What Demonica does

When a section manager is built with a shadow pass (S1), "Everything"
asynchronous occlusion becomes "Only Shadows": the terrain search runs inline and
only the shadow search goes to the search thread. "Only Shadows" is upstream's
default, so this changes nothing unless the player chose "Everything".

## Why

With the shadow pass first in the frame (S7), `updateForShadowPass` runs the
frame's terrain search, and the terrain pass's `update` then uses it without
joining. An asynchronous terrain search would be joined that frame only if chunk
uploads happen to force it (`uploadChunks` calls `finishAllGraphUpdates`);
otherwise the terrain pass draws the previous frame's lists. The plan also kept every
search that shares the lattice with the shadow search synchronous, so that no
race on the lattice can arise without a patch to it.

## Proposal

Upstream to decide whether "Everything" is meant to work with a shadow pass. If
it is, and the terrain pass then joins the terrain search it did not run, this
clamp can go.
