# S15: the fog service under a GL state manager

Draft, not sent. Replaces `seam.GLStateManagerFogServiceMixin` (group BASE:
needed with shaders off too).

## Problem

forge122's `GLStateManagerFogService` reads vanilla's cached
`GlStateManager.fogState` and `EntityRenderer.fogColor*`. A GL state manager that
takes over vanilla's fog calls (GLSM, used by Demonica and Angelica-derived
mods) leaves that cache unchanged, so every terrain section is drawn in solid fog
colour (confirmed in [SPIKE.md](../SPIKE.md), section 2). A mod cannot supply its
own service reliably: `ChunkShaderFogComponent.FOG_SERVICE` is
`ServiceLoader.load(FogService.class).findFirst()`, and which service comes first
depends on classpath order.

## Proposal

Pick the service with the highest priority instead of the first one:

```java
public interface FogService {
    default int priority() { return 0; }
    ...
}
public static final FogService FOG_SERVICE = ServiceLoader.load(FogService.class).stream()
    .map(ServiceLoader.Provider::get).max(Comparator.comparingInt(FogService::priority)).orElseThrow();
```

Demonica would then ship a GLSM-backed service with a higher priority (and allow
that one `META-INF/services` entry in `verifyDistributedJar`).

## Also worth proposing

forge122 reports fog shape 0 (spherical), but vanilla 1.12's fog is planar
(eye-plane distance). Demonica's service reports `FOG_SHAPE_PLANAR`, which moves
the frame edges closer to vanilla.

That choice turns fog occlusion off. For planar fog, `getEffectiveRenderDistance`
scales the cutoff by the frustum's widest secant, which it computes from a
projection matrix, but both searches pass `null` (`update` and
`updateForShadowPass` call `createTerrainRenderList(viewport, null, …)` and
`getSearchDistance(null)`), so planar fog always searches the full render
distance. Under vanilla's default fog that costs little (the fog ends at the
render distance), but under dense fog (water, lava, blindness) sections hidden
by fog are still searched and drawn. Passing the terrain projection matrix into
the search would restore fog occlusion for planar fog, on every loader.
