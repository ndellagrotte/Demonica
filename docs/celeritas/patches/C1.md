# C1: mods that hook vanilla's chunk rebuild

Draft, not sent. Replaces `seam.ChunkBuilderMeshingTaskCompatMixin` (group COMPAT).

## Problem

Some mods do their part of chunk meshing from inside vanilla's
`RenderChunk.rebuildChunk` or `ChunkRenderDispatcher.uploadChunk`, which Celeritas's
`ChunkBuilderMeshingTask` replaces, so under Celeritas they silently do nothing:

- **Component Model Hider** (Modular Machinery CE's block-model hiding) redirects
  the `renderBlock` call in `rebuildChunk` to skip hidden positions, and arms a
  thread-local flag around it that its other hooks (in `BlockModelRenderer` and in
  CodeChickenLib) consult, so that a hidden block stops culling its neighbours'
  faces. Under Celeritas hidden blocks are meshed, and still occlude.
- **LittleTiles** keeps each tile entity's geometry in its own vertex cache and
  appends it to the vanilla upload buffer in `uploadChunk`. Under Celeritas every
  LittleTiles block that is not a full block is invisible. It also flips
  `RenderChunk.setNeedsUpdate` when a cache is rebuilt, which Celeritas never polls.

## Proposal

Two small extension points in `ChunkBuilderMeshingTask.execute`, with no mod
names in Celeritas:
- a per-block "skip" predicate consulted before a block is meshed (the hider's
  hidden positions), and a begin/end callback around the build (its flag);
- a callback after the block loop that may append vanilla-format geometry to the
  layer buffers before `convertVanillaDataToCeleritasData` (LittleTiles' caches).

LittleTiles' rebuild signal can already use `SimpleWorldRenderer.scheduleRebuildForChunk`.

## What Demonica drops

`ChunkBuilderMeshingTaskCompatMixin`: a `@WrapMethod` on `execute` (the hider's
build flag, only while the hider is installed), a `@WrapOperation` on its
`canRenderInLayer` call (hidden positions render in no layer; it composes with
S10's wrapper of the same call), and a `@WrapOperation` on its
`convertVanillaDataToCeleritasData` call (LittleTiles' geometry). Every call into a
mod's compat class is behind a `Mods` flag, so no mod class loads without its mod.

The neighbour rule needs no patch: with the hider installed, blocks next to a
hidden one take the vanilla path (S13's switch), where its own redirects apply.
