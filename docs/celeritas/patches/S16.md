# S16: no face culling in the shadow pass

Draft, not sent. Replaces `internal.DefaultChunkRendererMixin` (group SHADOW).

## Problem

`DefaultChunkRenderer.render` culls the faces of each section that point away
from the camera (`useBlockFaceCulling()`, `DefaultChunkRenderer.java:66`). In the
shadow pass that camera is still the player's, and shadows are cast by faces
that point away from the player as often as not. The modern loaders turn it off
while Iris renders shadows (`ModernChunkRenderer.useBlockFaceCulling`).
`SectionRenderDataStorage` already caches a second batch per region for this
case.

## Proposal

forge122's `VintageRenderSectionManager.ChunkRenderer.useBlockFaceCulling()`:

```java
return CeleritasVintage.options().performance.useBlockFaceCulling
    && !(provider != null && provider.isRenderingShadowPass());
```

## What Demonica drops

The `@ModifyExpressionValue` on the `useBlockFaceCulling()` call in `render`.
MixinExtras applies it after `QuarantinePlugin`'s check, so the plugin reports it
as applied later; the exported bytecode (2026-09-23) shows it in place.
