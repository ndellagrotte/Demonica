# S3: the section manager knows when it is in the shadow pass

Draft, not sent. Replaces `isInShadowPass()` in
`seam.VintageRenderSectionManagerShadowMixin` (group SHADOW).

## Problem

`RenderSectionManager.isInShadowPass()` picks the render lists, rebuild queues and
visibility snapshot a caller sees (`getCurrentRenderListManager`), and entity
culling skips its section test in the shadow pass
(`CeleritasWorldRenderer.isEntityVisible`). forge122's manager never overrides
it, so it is always false. The modern loaders answer from Iris's
`ShadowRenderingState`.

## Proposal

```java
@Override
public boolean isInShadowPass() {
    return this.hasShadowPass() && provider != null && provider.isRenderingShadowPass();
}
```

The `hasShadowPass()` guard matters: without shadow lists,
`getCurrentRenderListManager()` would return null.

## What Demonica drops

The added override. `AnchorInventoryTest.forge122DoesNotOverrideTheSeamHooks`
fails if upstream adds its own, which would make the patch a duplicate.
