# S19: the chunk tracker's neighbour radius

Draft, not sent. Replaces `internal.ChunkTrackerMixin` (group DEGRADE).

## Problem

`ChunkTracker.requiredNeighborRadius` is private. Iris's Distant Horizons uniforms
need it (`CameraUniforms`, through `com.demonica.celeritas.ChunkTrackers`).
Actinium's fork added a getter.

## Proposal

```java
public int getRequiredNeighborRadius() {
    return this.requiredNeighborRadius;
}
```

## What Demonica drops

The `@Shadow` read and `ChunkTrackerAccess`. `ChunkTrackers` calls the getter.
Without the patch, the radius reads as 0 and the uniform falls back to its
default.
