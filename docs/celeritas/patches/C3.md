# C3: mods that draw in vanilla's block-entity batch

Draft, not sent. Replaces `seam.CeleritasWorldRendererCompatMixin` (group COMPAT).

## Problem

Some mods draw block entities of their own from inside vanilla's
`RenderGlobal.renderEntities`, right after its
`TileEntityRendererDispatcher.preDrawBatch()` call, so that their draws join the
batch that `drawBatch` closes. Celeritas cancels `renderEntities` before that call
and draws block entities in `CeleritasWorldRenderer.renderBlockEntities` instead,
so under Celeritas those draws never happen:

- **Moving Elevators** (1.4.12) draws the block entities of a moving cage there
  (`ElevatorGroupRenderer.renderBlockEntities`, from its `LevelRendererMixin`).
  Its `@Pseudo` mixin for Vintagium targets
  `me.jellysquid.mods.sodium.client.render.SodiumWorldRenderer.renderTileEntities`
  at the same call, a class Celeritas does not have. Under Celeritas a chest or
  sign in a moving cage disappears for the ride and reappears when the cage lands.

Celeritas already draws the `RenderGlobal.setTileEntities` set for mods that
inject a renderer there; that covers tile entities in the world, not draws a mod
makes itself.

## Proposal

A block-entity pass callback in `CeleritasWorldRenderer.renderBlockEntities`,
with no mod names in Celeritas: listeners registered with a static setter, called
with the partial tick right after `preDrawBatch()`, inside the batch, as vanilla
did. Mods written for Vintagium could move their `SodiumWorldRenderer` hook to it,
and nothing would need to target Celeritas internals.

## What Demonica drops

`CeleritasWorldRendererCompatMixin`: an `@Inject` after the `preDrawBatch()` call
in `renderBlockEntities` (full descriptor; the erased bridge calls it) that calls
`ElevatorGroupRenderer.renderBlockEntities` with the context's partial tick, only
while Moving Elevators is installed. The call into the mod's compat class is
behind a `Mods` flag, so no mod class loads without its mod. S9's HEAD injection
has entered Iris's block-entity phase by then, so the draws take the pack's
block-entity program.
