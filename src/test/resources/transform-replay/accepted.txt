# Differences TransformCorpusReplayTest tolerates between the recorded TauMC output and a replay
# (docs/glsl-transformer_adoption/ADOPTION_PLAN.md, 3.5). One entry per line:
#
#   <case glob> | <stage> | <reason>
#
# <case glob> matches the case's path under the corpus directory (for example bsl/00012-COMPOSITE-1a2b3c4d) or its
# directory name alone; '*' matches within one path segment, '**' across segments, '?' one character. <stage> is
# vertex, geometry, tess_control, tess_eval, fragment, compute, compat (GLSM's mod-shader cases), error-succeeded or
# error-threw (a case recorded with outcome=error, TauMC threw, whose replay succeeds, or throws something else; the
# replay's output is written to build/reports/transform-replay/<case>.error.diff; an entry accepts only the outcome it
# names, so a replay that starts to throw is not accepted by an entry written for one that succeeded) or '*' (any
# output stage, not the two error outcomes); any other stage fails the test. Every entry needs a reason a reader can
# check; an entry without one fails the test. An entry whose reason starts with "S7 pending" is verified by the
# replayer: the stage's difference must be the TauMC engine's adaptive-shadow-bounds rewrite and nothing else (the
# TauMC engine rerun with the PCF helpers hidden from that rewrite must give the replay's output), or the stage fails.
#
# Step 2 (2026-09-28): empty. The TauMC engine replays its own recordings identically.
