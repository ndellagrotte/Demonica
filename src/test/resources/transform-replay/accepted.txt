# Differences TransformCorpusReplayTest tolerates between the recorded TauMC output and a replay
# (docs/glsl-transformer_adoption/ADOPTION_PLAN.md, 3.5). One entry per line:
#
#   <case glob> | <stage> | <reason>
#
# <case glob> matches the case's path under the corpus directory (for example bsl/00012-COMPOSITE-1a2b3c4d) or its
# directory name alone; '*' matches within one path segment, '**' across segments, '?' one character. <stage> is
# vertex, geometry, tess_control, tess_eval, fragment, compute, compat (GLSM's mod-shader cases), error-succeeded or
# error-threw (a case recorded with outcome=error, TauMC threw, whose replay succeeds, or throws something else; the
# replay's output is written to build/reports/transform-replay/<case>.error.diff; an entry accepts only the outcome it
# names, so a replay that starts to throw is not accepted by an entry written for one that succeeded), threw (a case
# recorded with an output whose replay throws; Step 7b) or '*' (any output stage, not the three outcomes); any other
# stage fails the test. Every entry needs a reason a reader can
# check; an entry without one fails the test. When an engine other than taumc replays, an entry whose case glob matches
# a replayed case but that tolerated no difference in that run is stale and fails the test too (Step 7), so an entry
# must go when its difference goes; entries for cases the run did not replay (another corpus, a filtered kind) are not
# judged.
#
# Step 2 (2026-09-28): empty. The TauMC engine replays its own recordings identically.
#
# Step 8 (2026-09-29): the new engine is the default, and :test replays the committed mini-corpus
# (src/test/resources/transform-corpus) on it without -PglslCorpusDir. Every entry below was reviewed: each names a

# stale=0), each test it cites exists, and the compile claims were checked again with glslangValidator 16.4.0 on both
# engines' outputs (report S08-flip-default.md, "accepted.txt review"). No pack corpus case needs an entry.
