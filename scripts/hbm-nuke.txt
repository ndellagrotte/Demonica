# NTM-CE (HBM's Nuclear Tech: Community Edition) nuke and bomb particles, shot without a pack, under Complementary
# Reimagined and under Complementary Unbound + Euphoria Patches. Run with -PwithHbm=<NTM-CE jar>; the camera is the
# profile one (absolute tp, so runs are comparable; it looks north-east, yaw 225, so the effects sit at +x -z of it). The effects are spawned client-side with the harness's hbmfx step
# (HbmEffectNT.summonParticle), which is what NTM-CE's effect packet does:
#   Muke        = ParticleMukeWave + ParticleMukeFlash (layer 3, NTMImmediate client arrays, additive blend)
#   TinyTot     = ParticleMukeCloud (layer 3, NTMImmediate, normal blend, explosion.png) + a wave
#   Smoke_Cloud = ParticleExSmoke (instanced: InstancedParticleRenderer + lit_particles in RenderWorldLastEvent;
#                 otherwise a layer-1 particle written into vanilla's buffer)
#   hbm:entity_effect_torex = the mushroom cloud entity (instanced cloudlets, flash, flare)
